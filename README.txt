JAMIATUL MADINA BANDHEWA WEBSITE
=================================

यह एक तैयार Static Website है। इसमें अभी नमूना विद्यार्थी/रिजल्ट/नोटिस हैं।

GitHub Pages पर लगाने के आसान चरण:
1. GitHub पर नया account/repository बनाएं।
2. इस ZIP को extract करें।
3. index.html, style.css, script.js और बाकी folders/files को repository में upload करें।
4. Repository में Settings > Pages खोलें।
5. "Deploy from a branch" चुनें।
6. Branch: main और folder: / (root) चुनें।
7. Save करें।
8. कुछ देर बाद आपकी वेबसाइट github.io लिंक पर खुल जाएगी।

वास्तविक डेटा डालना:
- index.html में Students table में नाम/कक्षा बदलें।
- Result table में अंक/ग्रेड डालें।
- Attendance में तारीख और गैरहाजिर नाम डालें।
- PDF के लिए pdfs नाम का folder बनाकर PDF रखें और संबंधित link को बदलें।

अगला बेहतर चरण:
इस basic version को आगे database जैसी सुविधा के बिना भी सुंदर तरीके से चलाया जा सकता है। यदि बहुत सारे विद्यार्थी हैं, तो मैं अगला version ऐसा बना सकता हूँ जिसमें अलग-अलग कक्षा, तारीख के अनुसार गैरहाजिरी, result search और PDF categories हों।
